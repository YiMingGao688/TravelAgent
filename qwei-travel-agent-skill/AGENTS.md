# 七维智行项目 Codex 指令

请优先使用 `.codex/skills/qwei-travel-agent/SKILL.md`。

本项目不是 OTA 平台，也不是普通地图导航工具，而是面向公众出行全过程服务的智能体平台。

核心能力：AI 结构化解析需求、地点解析与候选确认、高德路线/天气/POI、跨城出行链分段、行程规划表、模拟预约/订单、地图可视化、实时提醒与动态重规划、售后工单、服务报告。

禁止：不要把 mock 数据写死前端；不要没有经纬度就规划路线；不要模糊地点直接默认；不要用 setTimeout 假装思考；不要把跨城行程简化为单段路线；不要爬 12306 或 OTA 页面；不要真实支付。
